# Food · 红烧肉双视频陪做

iPhone 原生做菜 App。首个场景是家用炒锅版红烧肉：上方看当前步骤的示范，下方看后置相机拍到的自家锅面，配合普通话播报和焖煮倒计时做完整道菜。

Swift + SwiftUI，iOS 26 Liquid Glass，最低 iOS 26。全流程离线可用，相机帧只在内存中处理。

## 构建

1. 用支持 iOS 26 SDK 的 Xcode（26 或更新）打开 `Food.xcodeproj`。
2. 在 Food target 的 Signing 里选自己的 Team。Bundle ID 为 `com.alicelikeeat.food`，可按需修改。
3. 选 iPhone 真机或 iOS 26 Simulator，运行 `Food` scheme。
4. 测试：`⌘U`，或

   ```sh
   xcodebuild test -project Food.xcodeproj -scheme Food \
     -destination 'platform=iOS Simulator,name=iPhone 17'
   ```

工程使用 Xcode 的文件夹同步分组：往 `Food/` 或 `FoodTests/` 里加文件即自动进入对应 target，不用改工程文件。

### 短测试计时

调试构建里，做菜页右上角「设置」有「短测试计时」开关（焖煮 20 秒、延长 10 秒），下次开始做菜生效。也可加启动参数 `-settings.shortTimers YES`。

## 真机权限

| 权限 | 何时申请 | 拒绝后 |
|---|---|---|
| 相机 | 进入做菜页 | 观察区显示文字说明，示范、确认、计时照常 |
| 通知 | 开始一次新的做菜 | 前台照常计时；回到 App 显示「待检查」 |
| 麦克风 + 语音识别 | 在设置里打开「语音确认」时 | 开关保持关闭，所有操作走按钮 |

语音确认只在设备支持普通话本地识别时可用，每次点麦克风收听约 8 秒；播报时自动停止收听。

## 结构

```
Food/
  App/          FoodApp、CookingViewModel（把各部分接起来）
  Models/       Recipe（菜谱）、CookingSession + SessionEngine（纯逻辑状态机）
  Services/     会话与备注存储、通知计时、播报、语音确认
  Camera/       相机 / Simulator 样本两种画面来源、预览层、提示视频播放器
  Observation/  糖色颜色规则、多帧稳定器、像素采样
  Views/        首页、双视频做菜页、焖煮状态、完成页
  Resources/    hongshaorou.json、Media/（短片与参考色块）
FoodTests/      步骤推进、重复确认、计时恢复、到期后延长、观察逻辑
Tools/          make_placeholders.sh（生成占位素材）
```

几个关键设计：

- **推进只有一个入口。** 点按和语音确认都调用 `confirm(stepID:)`，带上发起时看到的步骤 ID；步骤已变就被忽略，所以不会连跳两步。
- **计时只存截止时间。** 剩余时间永远是「截止时间 − 现在」。切后台、锁屏、杀进程后重开都从磁盘上的会话重算。
- **一个计时一个通知 ID**（`timer.<菜谱>.<步骤>`）。延长时用同一 ID 覆盖原提醒，离开会话时移除。App 在前台时系统通知不出声，由 App 自己播报一次。
- **到点只进「待检查」。** 是否继续焖、是否收汁都由用户点。
- **观察结果只产生提示。** 没有任何识别输出能替用户换步。
- **一套捕获会话。** 预览层和分析输出共用；分析按每秒 2 帧取样并丢弃积压帧，离开糖色步骤即断开分析输出。焖煮时相机默认停用，点「打开锅面」才恢复。

## 糖色观察：视觉辅助原型，不是模型识别

当前实现是锅面中心选区（画面中央约 40%）的平均颜色规则：按色相和亮度分成「偏浅 / 接近目标 / 可能偏深」，过曝、过暗、低饱和（蒸汽、白光）、色相不在糖色范围、选区亮度差异过大时判为「看不清」，界面回到「请对照上方示范」。连续 3 帧一致才更新，同一状态只播报一次。

阈值是照着合成色块定的，**没有用任何实拍糖色标定过**。在集成并验证真实模型之前，这个功能不能称为识别。已知局限：相机自动白平衡和曝光会让同一锅糖在不同灯光下读数漂移；没有单独的失焦检测。

## 菜谱

`Food/Resources/hongshaorou.json`：2–3 人份，五花肉 500 g，带盖炒锅。焖煮默认 40 分钟、延长 5 分钟，标记为 `"verified": false`——**时长和用量都还没经过试菜核定**，界面上也会提示以开盖检查为准。
